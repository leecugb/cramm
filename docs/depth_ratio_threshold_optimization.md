# 深度比阈值优化与影响审计

> 日期：2026-11-20  
> 搜索脚本：`docs/optimize_depth_ratio_thresholds.py`  
> **边界：阈值来自参考谱衍生开发数据，不是独立校准，也不构成场景精度证明。**

## 1. 优化对象与约束

使用扩展低频 EMIT 合成批次，展开 77 规则候选矩阵，并对两组共享阈值进行网格搜索：

- 纯白云母/伊利石：0.500–0.800，步长 0.025；
- 三条高岭石—白云母混合规则：0.300–0.600，步长 0.025。

选择规则依次为：

1. 最大化定向混合光谱的正确组分集合数；
2. 纯净参考精确恢复不得少于当前 0.6/0.4 配置；
3. 并列时提高参考恢复、减少纯白云母接管和无输出；
4. 最后选择最接近当前值的候选。

模拟矩阵先验证：

- 无比值约束时逐条复现 M00；
- 当前 0.6/0.4 时逐条复现 M10；
- 正确组分集合标记与真实运行器一致。

三项检查全部通过。

## 2. 选择结果

| 指标 | 当前 0.6/0.4 | 候选 0.6/0.55 |
|---|---:|---:|
| 正确混合组分集合 | 215 | **229** |
| 高比值干扰组正确集合 | 140 | 140 |
| 高岭石/蒙脱石组正确集合 | 75 | **89** |
| 纯净参考精确恢复 | 87 | **89** |
| 纯白云母/伊利石赢家 | 337 | 327 |
| 无输出 | 139 | 139 |
| 纯干扰参考被纯云母接管 | 0 | 0 |

纯白云母/伊利石阈值保持 **0.6**，高岭石—白云母混合阈值由 **0.4 提至 0.55**。

更激进的纯规则阈值 0.5 虽可得到 238 条正确集合，但纯净参考精确恢复由 87 降至 77，违反保留约束，因此未采用。

## 3. 按端元对折叠核验

| 折叠 | 当前正确集合 | 候选正确集合 |
|---|---:|---:|
| 0 | 66 | 69 |
| 1 | 37 | 38 |
| 2 | 17 | 19 |
| 3 | 39 | 41 |

五个折叠均改善，合计增加 14 条。高比值组各折叠不变，改善全部来自低比值粘土组；无输出数量不变。

## 4. 真实分类器复核

将三条混合规则的 `max_depth_ratio_feat1_over_feat0` 改为 0.55 后：

- 实际 CRAMM 分类器与所选模拟矩阵在全部 6,053 条光谱上逐条一致；
- 正确混合集合为 229，纯净参考精确恢复为 89；
- SYN02031 的混合规则比值 0.4784 低于新上限，结果由纯 `muscovite_medAl` 恢复为正确的 `kaolinite.5+muscoviteMedAl.5`；
- 仲裁的 5 次亚型改善、0 次退化保持不变；
- 完整离线测试：**40 passed / 0 failed**。

优化脚本、候选表、折叠表和缓存均已独立重跑并逐位/逐字节一致。

## 5. 真实 EMIT 整景影响

与同一引擎的 0.4 配置相比，0.55 在整景上改变 **28,215 个标签**。主要转移为：

- `muscovite_lowAl → kaolinite+muscovite_mix_intimate`：15,514；
- `muscovite_medAl → kaolinite+muscovite_mix_intimate`：10,274；
- 其他纯白云母到高岭石—白云母混合规则的转移也较多。

这说明新阈值显著扩大了高岭石—白云母混合规则的承接范围。没有独立场景真值时，不能将这种变化直接称为精度提升。

## 7. 当前结论

- **0.55 是有开发数据支持的候选改进**，可改善正确混合集合并修复代表性误判；
- 纯净参考保留未下降，五个端元对折叠均改善；
- 但它不是独立验证后的通用阈值；
- 整景标签变化显著；黄金回归已于 2026-11-24 在逐像素审计后重建并通过，但独立场景验证仍是发布冻结前的必要工作。
