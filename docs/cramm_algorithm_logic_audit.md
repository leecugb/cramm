# CRAMM 当前算法逻辑综合审计

> 日期：2026-11-20  
> 对象：当前工作树中的 `cramm/`、`rf.json` 与验证脚本  
> **结论范围：当前代码与已执行测试，不是对所有输入的形式化证明，也不是独立地质精度验收。**

## 1. 总结结论

当前 CRAMM 的核心算法链路在已测试路径中能够按配置执行，未发现诊断约束、深度比或仲裁被系统性绕开。当前需要解决的主要问题已从“逻辑是否执行”转为：

1. **阈值与窗口变更是否正确且可独立验证**；
2. **混合规则被排除后由哪条规则接管**；
3. **黄金场景基线尚未随 intentional changes 审查更新**；
4. **扰动鲁棒性与真实场景地质验证不足**。

当前状态适合继续开发与验证，不应直接冻结为发布终态。

## 2. 核心执行链

### 2.1 输入与参考重采样

- 输入为反射率光谱/影像、中心波长、FWHM 和有效波段掩膜。
- 参考谱使用统一 0.35–2.50 µm、1 nm 网格，运行时按传感器配置进行高斯重采样。
- EMIT 生产读取器保留 float32 波长/FWHM 算术；合成复核已按同一 dtype 重建。
- 当前测试场景的均值掩膜与 `good_wavelengths` 一致，均为 244 个基础有效波段。

### 2.2 单规则评价与约束顺序

每条规则依次执行：

1. 诊断特征连续统移除、闭式最小二乘拟合、fit/depth/raw-depth 计算；
2. 绝对排除特征；
3. 相对排除特征；
4. 可选深度比上限；
5. weighted fit、weighted depth 和 fit×depth 总约束。

`alive_rows` 只跳过已被拒绝像元的后续计算，NaN 继续传播。当前专项审计证明其与强制全量计算逐位一致，不是跳过未拒绝像元的约束。

### 2.3 最佳匹配与无输出

- 所有被拒绝规则保留为 NaN；仅在 argmax 前暂存为 0，同时保存 `fit_nan` 供仲裁验收使用。
- 最佳匹配为 **weighted fit argmax**，不是 fit × depth argmax。
- 最大 fit 不为正时视为无输出，不把默认索引 0 当成有效鉴定。

### 2.4 深度比语义

- 使用未加权原始拟合深度 `d1/d0`。
- 纯白云母/伊利石规则当前上限为 **0.6**：高超阈排除纯净归属，不是否定白云母组分存在。
- 三条高岭石—白云母混合规则当前上限为 **0.55**：高超阈排除相应混合解释。
- 约束只删除候选，不直接输出通用混合标签。
- 当前库没有直接的白云母/伊利石—蒙脱石混合规则。

### 2.5 吸收中心与仲裁

- 白云母、绿泥石和碳酸盐分别使用 `mus_center`、`chl_center`、`cal_center`。
- 仲裁只处理当前带窗赢家；目标必须在仲裁前通过完整约束且 fit > 0。
- 白云母/绿泥石为族内无缝窗口，碳酸盐按 abundant/plain 分层，避免串层。
- 无窗口、出窗、歧义或无有效中心时保持原赢家。
- 翻转后重拟合一次；非有限或越出目标窗时回退翻转前中心，避免标签—中心不一致。

- 纯干扰矿物接管；

这些指标不能合并为一个含义不清的“精度”。

## 4. 当前合成测试评价

当前完整算法 M11（0.6/0.55 + 仲裁）在 6,053 条扩展低频合成数据上，按“单参考精确规则 / 混合完整组分集合”严格口径：

| 子集 | 严格任务失败率 |
|---|---:|
| 全部 | **74.62%** |
| 单参考 | 39.51% |
| 二元混合 | 85.82% |
| 高比值干扰定向组 | 88.89% |
| 高岭石/蒙脱石低比值组 | 92.94% |

这些数字是参考谱衍生、含扰动自检结果，不能作为真实场景误判率。混合指标尤其严格，反映的是完整组分集合恢复，而非单族 Top-1 精度。

同批数据的“至少一个真值族重叠”结果分别为：单参考 82.30%、二元混合 70.68%、全体 73.48%。因此，74.62% 应称为**严格任务失败率**，不能与通常的矿物族误判率混用；族重叠口径会接受部分命中和弱混合命中，也不能单独当作精度。

阈值 0.55 相对 0.4 将正确混合集合由 215 提至 229，总体严格误判率由 74.86% 降至 74.62%，但仍存在：

- 纯净参考扰动误排除；
- 低比值粘土组恢复下降；
- 混合规则被拒绝后由纯规则或无关规则接管；
- 蒙脱石专用规则缺失。

## 5. 剩余逻辑风险与边界

### 5.1 缓存契约

原地修改规则或参考束后必须调用 `invalidate_caches()`。当前代码不会自动识别所有原地内容修改；既有测试明确保留该 stale-trap。扩展字段在构造和缓存失效时会校验，但不能把该契约省略为“无需刷新”。

### 5.2 中心估计的剩余边界

当前已有目标窗口后验回退，但没有完整的中心不确定度模型，也没有单独强制正曲率与顶点三点区间门控。当前退化样本均为正曲率且顶点在区间内，因此这些不是本轮退化原因；它们仍是需要补充测试的潜在异常路径。

### 5.3 仲裁边界与覆盖

- 白云母/绿泥石窄窗口对亚波段中心噪声敏感；
- 出窗保持原赢家限制了极端亚型纠正；
- 碳酸盐 abundant/plain 共享参考曲线时，中心无法纠正丰度层误归；
- 无窗混合规则不参与仲裁是明确设计。

### 5.4 独立验证不足

所有合成阈值和窗口评估仍以 CRAMM 参考谱为基础，存在开发集优化和自洽性偏差。需要独立标本、独立模板或参数化前向真值，以及场景地质证据。
