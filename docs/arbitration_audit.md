## 一、仲裁器判定逻辑(三族共用的唯一实现)

`classify` 每段按 **argmax(FIT) 初选赢家 → 三族中心图层计算 → mus → chl → cal 顺序三次仲裁**;
串并行路径共用 `_reassign_by_absorption_center`(bit-exact,黄金链钉死)。

对每个"赢家属于本族带窗规则"的像元,用二次拟合吸收中心计数命中窗口数:

| 命中数 | 语义 | 动作 |
|---|---|---|
| 0(出所有窗/中心无效) | 无效 | 保守保持原匹配 |
| ≥2(重叠/重复窗) | 歧义 | 保持原匹配 |
| 恰好 1 且非当前匹配 | 排他落入他窗 | **翻转 + 按目标规则 feat0 端点重拟合中心一次**(单趟不迭代) |

翻转还需通过目标接受门:目标规则 fit 非 NaN **且 > 0**(`fit==0` 非 NaN 的自定义规则
被显式挡下,防止像元被翻转到与背景不可区分的状态——classifier.py:388-394)。

### 五道门控(全部实测,C/D/E/H 组)

1. `member`:赢家 ∈ 本族带窗规则列(族内无窗成员 illite/混合规则天然排除)
2. `fit_pos`:像元存在任一正 fit
3. `mus_c > 0`:中心有效(NaN 已折叠为 0;未折叠 NaN 亦被挡,防御纵深)
4. `uniq`:唯一命中(歧义保持)
5. `ok`:目标 ≠ 当前、目标 fit 非 NaN、目标 fit > 0

### 窗口边界语义:左闭右开 `[lo, hi)`

拼接点中心唯一命中**右侧**窗(实测 2.200→medAl、2.206→lowAl、2.245→lowFe 自身);
族窗右端开区间(2.220、2.266)出窗保持。无缝拼接 + 左闭右开 = 每中心恰一归属,无死区无重叠。

## 三、中心计算与重拟合(G 组)

- 中心由 `_get_quadratic_center` 在**输入光谱**上对赢家规则 feat0 窗做连续统去除 + argmin
  三点抛物线顶点拟合;窗口边缘极小值(无法取三点)与 ±inf 顶点(精确共线)折叠为 NaN → 0。
- 翻转后用**目标规则**端点重拟合一次,保持中心与最终归属一致;实测真实谱翻转
  medhighAl→medAl,重拟合值与独立直接计算逐比特一致(2.201620)。
- 精确共线(平直 0.5,2 的幂保证端点均值精确)重拟合 NaN → **正确回退**翻转前中心。
- 重拟合失败回退注释见 classifier.py:410-416。

## 四、发现与观察(均为 P3,不建议改动)

1. **近似共线的有限野值顶点(G3)**:精确共线触发 NaN 回退,但**近似**共线
   (如平直 0.3 光谱,端点均值含 1-ulp 噪声,con 在 1±1e-16 抖动)时抛物线顶点
   被放大为**有限**野值(实测 2.2415),绕过 NaN 回退。
   **生产不可达**:翻转门控要求目标规则 fit > 0,而 fit 计算含同一 feat0 窗的
   depth 约束——平直窗给不出正 depth,不可能通过;仅"自定义无 depth 约束规则库"
   理论可达,且野值需恰好落入 nm 级窗口才会改变归属。处置:记录在案,不改数值路径。
2. **`classify_spectrum` 无仲裁**:单谱 Top-N 路径(classifier.py:1442-1489)只做
   逐规则 fit 排序,不计算中心、不仲裁。Top-1 可能与 `classify` 仲裁后的最终归属
   不同(对会被翻转的像元)。属既有设计差异(Top-N 呈现的是仲裁前证据),未见文档
   明示;如对外提供单谱 API 建议补一句说明。
3. **测试覆盖对账**:绿泥石仲裁翻转、碳酸盐按层仲裁(v1.5.0 起)、族锁定各有专测
   (test_core.py:282/328/370);**白云母族翻转无专测**,当前由本审计 D4/C1/C2
   与黄金链间接覆盖——可选择把审计脚本 C/D 组移植为单测(非必须)。
