# 白云母吸收波长仲裁逻辑专项审计

> 日期：2026-11-18  
> 当前代码：`cramm/classifier.py`  
> 当前窗口：`cramm/data/rf.json`  
> 复核数据：`output/synthetic_emit_v2/`（生产 float32 波长/FWHM）与 `output/synthetic_emit_ablation_v3/`  
> **边界：参考谱衍生结果用于执行与敏感性审计，不是独立亚型精度评价。**

## 1. 配置与参考锚点

四个纯白云母规则按左闭右开 `[lo, hi)` 窗口无缝覆盖 2.195–2.220 µm：

| 规则 | 窗口 (µm) | 宽度 (nm) | 1 nm 中心 (µm) | 生产 EMIT 中心 (µm) | 清洁自检 |
|---|---|---:|---:|---:|---|
| medhighAl | [2.195, 2.200) | 5 | 2.197356 | 2.197851 | 正确，无翻转 |
| medAl | [2.200, 2.206) | 6 | 2.201620 | 2.202123 | 正确，无翻转 |
| lowAl | [2.206, 2.210) | 4 | 2.207044 | 2.207752 | 正确，无翻转 |
| Fe-rich | [2.210, 2.220) | 10 | 2.212625 | 2.211284 | 正确，无翻转 |

这里的中心由各规则自身连续统端点和三点抛物线估计，是自洽性锚点，不是独立化学真值。生产 EMIT 中心均落在自身窗口内，距最近边界约 1.28–2.15 nm。

2.2 µm 附近的 EMIT 波段间距约 **7.4 nm**。medhighAl、medAl 和 lowAl 窗口宽度分别为 5、6、4 nm，均不大于该采样间距。抛物线插值可以给出亚波段中心，但不能消除输入噪声带来的中心位移。

## 2. 实际执行顺序

1. 对所有规则完成诊断特征、排除特征、深度比和 weighted constraints；NaN 候选在 argmax 前暂存为 0，但 `fit_nan` 保留其“被拒绝”身份。
2. weighted-fit argmax 产生原赢家；只有 fit > 0 才具有有效输出。
3. 若原赢家是四条带窗白云母规则之一，使用其 feat0 端点估计 `mus_center`。
4. 中心无效、为零、出所有窗口或命中多窗时，保持原赢家。
5. 中心唯一命中另一条规则窗口时，还要求目标规则在仲裁前 fit 非 NaN 且 > 0；否则保持。
6. 翻转后使用目标规则 feat0 端点重估一次中心，不迭代。
7. 伊利石及白云母混合规则没有窗口，作为赢家时保持 argmax 结果；这是明确设计，不是执行失败。

自定义规则的孤儿窗口、非法窗口和单成员活跃组现在会在构造或缓存失效时抛出 `ValueError`，不再静默跳过。

## 3. 执行与不变量核验

在生产 dtype 数据上：

- M00→M01 有 **28 次白云母翻转**；M10→M11 有 **27 次**。
- 所有翻转目标在仲裁前均已通过对应规则约束，验收失败 **0**。
- 翻转前后触发状态变化 **0**。
- 28 次 M00→M01 翻转后的中心全部仍位于目标窗口内，未发现“标签改变但中心不支持目标”的状态。
- 翻转前后重拟合中心的最大位移为 **0.210 nm**。
- 编译/直接路径、串行/并行路径和族锁定专项测试均通过。
- float32 生产波长与 float64 上采样的早期数据相比，白云母仲裁结论不变；早期 dtype 差异只影响两条干植被重复规则标签。

M00→M01 的白云母转移构成：

| 转移 | 次数 |
|---|---:|
| medAl → medhighAl | 8 |
| medAl → lowAl | 7 |
| lowAl → medAl | 5 |
| Fe-rich → lowAl | 3 |
| medhighAl → medAl | 2 |
| lowAl → Fe-rich | 2 |
| Fe-rich → medAl | 1 |

## 4. 8 条白云母退化的原因

8 条“原 argmax 正确、仲裁后错误”的白云母样本全部发生在 40 dB，并且全部跨越窗口边界：

| 指标 | 结果 |
|---|---:|
| 正曲率 | 8/8 |
| 顶点位于三点区间内 | 8/8 |
| 中心存储不一致 | 0/8 |
| 噪声中心偏移绝对值中位数 | 3.303 nm |
| 噪声中心偏移范围（带符号） | −4.221 至 +3.896 nm |
| 错误中心距边界的中位数 | 1.253 nm |
| 错误中心距边界的范围 | 0.103–2.937 nm |
| 仲裁后 fit 下降中位数 | 0.0478 |
| 连续统斜率本身的中心影响 | 小于 0.002 nm |

因此，退化的直接原因是**噪声使合法估计的中心越过无缝硬边界**，而不是中心计算、缓存、目标验收或重拟合被绕开。

当前仲裁允许一个中心估计值直接覆盖高 fit 的原赢家，即使目标 fit 较低。该行为符合现有设计，但缺少中心不确定度或边界余量约束。

## 5. 边界余量的反事实结果

仅针对这 8 条已知错误翻转，若边界余量内禁止翻转：

- 1 nm 可阻止 3/8；
- 2 nm 可阻止 6/8；
- 3 nm 可阻止 8/8。

这不是选择 3 nm 阈值的依据。当前批次没有可用于衡量“正确翻转被余量阻止”的正收益样本，直接据此调参会过拟合自检集。后续需要在独立标本或参数化中心真值上同时评价：

1. 错误翻转阻止率；
2. 正确翻转保留率；
3. 亚型精度与输出覆盖率；
4. 不同 SNR 和传感器采样下的边际收益。

## 6. 结论与建议

**白云母仲裁的预设逻辑能够运行，且本轮没有发现实现绕开。** 当前主要弱点是窗口边界对噪声硬敏感，尤其是宽度不大于 EMIT 采样间距的窄窗口。

建议保留现有实现作为基线，新增可审计的边界余量试验，不直接修改生产阈值。试验至少记录中心距边界、曲率、顶点区间、原/目标 fit 和翻转后窗口一致性。
