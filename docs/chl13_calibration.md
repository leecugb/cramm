## 1. 项目背景与核心问题

绿泥石与白云母的根本差异在于它有**两个金属–OH 吸收带**：2250 nm（Fe–OH 为主）与 2350 nm（Mg–OH 为主）。继 mica14（白云母 2200 nm 单带建模）之后，本项目为绿泥石族建立成分标定体系，立项核心问题是：

> **双带能否分离 Fe/Mg？**——mica14 单带建模中 Fe/Mg 共线不可分的痼疾，能否靠绿泥石的第二条带破解？

**裁决：不能（§5）——双带位 r=0.989，是同一置换信号的两份拷贝。** 但证伪换来三样更值钱的结果：触噪声地板的单带闭集模型（§6）、全链路价态免疫（§6.2）、可自动执行的 QC 体系（§8）。

## 3. 化学规程与结构式（Phase 1）

**结论先行：统一基准与闭集归一使 chl13 化学可直接互比；审计留痕的三条异常后来在离群台账全部兑现（§7）。** 规程如下。

**基准**：O₁₀(OH)₈ = 无水基 O=14，f = 28/Σcation_charge。
**位分配**：T 位 Si→AlIV 补 4；八面体 = AlVI+Fe+Mg+Mn+Ti(+Cr/Ni)，空位 = 6−octa（可正可负）；层间 Ca+Na+K 为杂质指示。
**闭集**：xAl/xFe/xMg = AlVI、Fe、Mg 对 S=AlVI+Fe+Mg 归一。
**价态分级**：A=实测双价态（CLI101)；B=Fe₂O₃(T)；C=FeO(T)；P=探针 apfu。

审计留痕：SMR-14 octa 6.35 超填（Ti 0.45 apfu）；SMR-15 Σox=102.56 vs Total 101；CHM102 层间 Ca 0.42（碳酸盐疑杂）。

## 5. 双带可行性裁决（Phase 2 关键决策点）

**裁决：双带不能分离 Fe/Mg——带位、反演、深度三个通道全部关闭；唯一正向收获是 2350 带为跨仪器稳健锚。** 四项检验如下。

| 检验 | 结果 | 结论 |
|---|---|---|
| r(pos2250, pos2350) | **0.989** | 双带位是同一信号两份拷贝 |
| 反演 R²：双带 vs 单带 | 0.793 vs 0.793 | **增益恰为零 → Fe/Mg 不可分** |
| 带深比 d₂/d₁ vs xAl | 含 CHM102 时 r=−0.81；剔除后 r=+0.165 | −0.81 是 CHM102 杠杆假象，**深度通道亦关闭** |
| 跨仪器对（CCa-1 NIC4 vs TIR) | pos2250 偏 3.1 nm；**pos2350 偏 0.2 nm** | 2350 带是跨仪器稳健锚 |

原计划的"双带联合模型分离 Fe/Mg"就此砍掉，建模重心回到单带闭集。

### 6.2 价态免疫定理（M6）

闭集分数 xAl/xFe/xMg 是归一比值，归一因子 f 严格抵消；NNLS 解混对正标量缩放协变，同样不变。
**Fe₂O₃(T)/FeO(T) 口径歧义与 Fe³⁺ 比例假设对带位建模零影响**（以 CLI101 实测 Fe³⁺/Fe=0.39 锚定、u~U(0,0.4) 做 300 抽 MC,std=0.00 实证）。B/C 级样本无需价态折让——这是绿泥石比 mica14 干净的又一原因。

### 6.3 噪声地板

**模型 LOO 已贴近重复测量与粒级噪声地板；唯一远超模型精度的误差源是跨制样系统差。**

| 层级 | pos2250 | pos2350 |
|---|---|---|
| RELAB 同制样重复（jb794a–f) | 0.6 nm | 1.0 nm |
| USGS NIC4 粒级 30–150µm | 0.5–0.9 | 1.4–2.3 |
| **跨制样（<45µm 筛分 vs 原粉）** | **5.2** | **18.1** ⚠️ |
| **模型 LOO** | **1.00** | **2.40** |

**应用红线：跨制样系统差（细粒筛分偏蓝）远超模型精度——对比必须同制样同粒级。**

## 8. 带形层与自动 QC（Phase 5）

**QC 三规则（depth/asym/c−pos 并集）4/4 捕获离群、13 标定零误伤；形状量与 xFe 共线，故形状层定位 = QC + 机理叙述，不进模型。**

![QC 形状空间](chl_fig7_qc_shape.png)

**图 7 | 光谱与化学两条证据链互补，兜住全部离群。** QC 接收盒（2250 带 asym vs c−pos）；蓝点 = 标定池，红叉 = 剔除标本，橙块 = CCa-2 六次重复。
NMNH83369 的平顶假象显形为 asym 1.47 超盒；CHM102 的 asym 因带塌陷无定义，由 depth 规则兜住；
SMR-14 落在光谱盒内——它的剔除依据是化学审计（Ti/octa）。

**QC 三规则（并集）**——4/4 离群捕获、13 标定零误伤：

1. **depth < 0.05**（任一带）→ 捕 CHM102(0.004/0.025)、CorWa-1(0.009/0.014)
2. **asym₂₂₅₀ > 1.45** → 捕 NMNH83369(1.47);CCa-2 重复样 ≈1.5 为软警告
3. **c−pos₂₂₅₀ ∉ [0.57, 5.8] nm** → 捕 NMNH83369(6.5)、CHM102(8.9)、CorWa-1(−0.1)、CAr-1(−27.2)

形状物理：c−pos 与 xFe 强反相关（−0.88/−0.92)——Fe–OH 加深红翼，离散极小点红移快于质心（mica14 翼部存储机制同构）;fwhm₂ 与 xFe 正相关（+0.91)。但所有形状量都与 xFe 共线 → **形状层不进模型，定位 = QC + 机理叙述**。

## 10. 应用指引（二龙南蚀变绿泥石反演）

**二龙南反演按以下七条执行：口径 → QC → 反演 → 制样 → 含量边界 → 跨仪器锚 → 备胎公式。**

1. **口径**:hull-CR,w=(2.20,2.30),v=(2.24,2.27),smooth=None；输出看 center（抛物线修正值），不看 discrete
2. **QC**：三规则过筛；asym 软警告（1.45–1.6 区间人工复核）
3. **反演**：建议正向迭代——给定 xAl 先验（0.15–0.20，本池典型区间），闭集解出 xFe/xMg
4. **制样纪律**：同制样同粒级对比；<45µm 细粒组分单独建档，不与粗粒混排
5. **含量边界**:2250 带 + QC 下绿泥石 ≥50% 含量可定量（误差 <1 nm)；更低含量只定性
6. **跨仪器复核**:2350 带（w=(2.30,2.42),v=(2.32,2.37)）跨仪器偏差仅 0.2 nm 级，作锚
7. **快速估计**（数据不全时备胎）:`pos2250 = 2244.9 + 20.6·Fe/(Fe+Mg)`,LOO 1.68 nm
