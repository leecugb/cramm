## 1. 低频扰动模型

本次不再对每个波段独立添加白噪声。新模型为：

1. 在完整 285 波段生成标准正态随机序列；
2. 使用 sigma = 6 个波段、半径 24 个波段的高斯核进行平滑；
3. 在有效波段上去均值并归一化为单位 RMS；
4. 按目标 SNR 缩放并加到清洁光谱；
5. 保留原有连续统斜率、随机种子、有效掩膜和低值截断记录。

平滑先于坏波段掩膜，避免掩膜间隙人为制造不连续。目标 SNR 仍为 40、25、15 dB。

噪声粗糙度以相邻有效波段差分 RMS / 噪声 RMS 衡量：

- 原白噪声中位数：1.4137；
- 低频扰动中位数：0.1760；
- 比值：**0.1245**，即高频变化显著降低。

清洁光谱、端元比例和真值语义保持不变。

### 6.1 指标语义校正：排混不等于误伤

如果规则目标是**纯净白云母/伊利石归属**，则含绿泥石、碳酸盐或绿帘石的混合光谱被排除出纯白名单是正确逻辑，不应把白云母检出下降自动解释为算法错误。

需要区分三种评价目标：

1. **纯净矿物分类**：纯参考应保留，混合光谱不应被纯规则承接；
2. **混合组分检出**：若目标是识别混合物中的白云母组分，则删除该候选会损失组分信息；
3. **混合规则解析**：应检查排除纯规则后是否进入正确混合规则，而不是仅检查白云母是否消失。

因此，本文中基于“优势端元命中”和“白云母检出”的负向变化，只有在相应评价目标下才构成退化。对于排混目标，更直接的证据是：完整组分集合命中由 0.0706 提升至 0.1079，配对改善 47 条、退化 0 条；干扰组分检出改善 113 条、退化 0 条。这些结果支持深度比具有实际的排混和混合解析价值。

按“纯净规则排除”语义进一步统计 1,260 条定向混合光谱：

- 纯白云母/伊利石赢家由 **275 条降至 57 条**，即 218 条混合光谱不再被纯规则承接；
- 正确混合组分集合由 **89 条增至 136 条**；
- 纯干扰矿物赢家由 373 条增至 385 条；
- 无输出由 65 条增至 87 条。

这表明高超阈约束确实实现了混合光谱的纯规则排除，并在部分样本中恢复了正确混合组分集合。无输出只表示没有剩余规则承接，既不等同于已恢复混合真值，也不自动等同于错误。当前代码不直接输出通用“混合光谱”标签；最终归属仍由剩余规则决定。明细见 `output/lowfreq_targeted_outcome_semantics.json`。

### 6.2 高比值也可排除高岭石/蒙脱石混合解释

高岭石或蒙脱石混入时，预期次/主特征深度比降低。因此，对于相应的混合规则，比值上限用于排除这种混合解释：`ratio >= threshold` 时，不再将该像元归为对应的白云母—粘土混合规则，而不是据此证明它是纯白矿物。

当前三条高岭石—白云母混合规则使用 0.4 阈值。其 EMIT 参考比值为：

- `kaolinite.5+muscoviteMedAl.5`：0.2375；
- `kaolinite.5+muscoviteMedhighAl.5`：0.1972；
- `kaolinite+muscovite_mix_intimate`：0.2292。

三者均低于 0.4，且在当前配置下均保持自识别。该分支与纯规则的 0.6 排混约束共用同一上限运算符，但解释的是不同规则归属。

当前库没有直接的白云母/伊利石—蒙脱石混合规则，只有 `kaolinite+smectite_mix_intimate` 等其他混合规则。因此，蒙脱石分支需要独立规则和参考验证，不能仅凭现有 0.4 字段宣称已经覆盖。

## 7. 结论与后续约束

1. **低频扰动下仲裁显示了条件性正收益**，但仍需独立标本验证。
2. **深度比应定位为纯白云母/伊利石规则的排混约束**，其价值取决于纯净分类、组分检出或混合规则解析的目标；不能把混合光谱的白云母检出下降一概记为误伤。
3. 后续评价必须同时报告目标保留、干扰检出、完整组分集合、优势端元命中和触发率。
4. 不建议仅凭当前自检集修改 0.6/0.4 阈值；应先建立独立混合样本集，并分别评估纯白云母、伊利石和不同混合比例。
5. 完整测试仍为 **40 passed / 0 failed**；低频数据、四配置预测和分层输出均已通过逐位复现。
